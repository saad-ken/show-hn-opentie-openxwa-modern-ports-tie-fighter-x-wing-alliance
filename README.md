# Show HN: OpenTIE and OpenXWA

## What it does

OpenTIE and OpenXWA are modern ports of Tie Fighter and X-Wing Alliance, respectively. They aim to bring back the classic space combat games using a modern JavaScript framework. The project aims to recreate the gameplay mechanics, spaceship designs, and overall experience of the original games while incorporating modern web technologies.

## How to run it

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/OpenTIE.git
   cd OpenTIE
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm start
   ```

4. **Open the game in your browser**:
   - Navigate to `http://localhost:3000` in your web browser to play the game.

## Setup steps needed

1. **Node.js and npm**:
   - Ensure Node.js and npm are installed on your machine. You can download them from [nodejs.org](https://nodejs.org/).

2. **GitHub account**:
   - You need a GitHub account to clone the repository.

3. **Basic understanding of JavaScript**:
   - Familiarity with JavaScript is recommended to understand the game logic and codebase.

## Files

- **index.html**: Main HTML structure of the game.
- **styles.css**: Styling and layout for the game.
- **game.js**: Game logic and rendering functions.
- **assets/tie-fighter.png**: Sprite for the Tie Fighter spaceship.
- **assets/x-wing.png**: Sprite for the X-Wing spaceship.
- **assets/space-background.jpg**: Background image for the game.
